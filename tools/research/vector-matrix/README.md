# Isolated prepared numerical matrix

These are review inputs at their original relative paths, not an installed
alternative product. Reconstruct the native-observation, prepared-domain and
hook-scale parents, then apply `vector-matrix-runtime.patch` with
`git apply --unidiff-zero`. Place these files at their original paths.

`VectorMatrix` stores and validates existing projected binary64 hints by original
window digest. It grants no source, Work or completion authority. `SearchProvider`
and `Warm` integration is in the patch. `VectorMatrixAudit` checks all prepared
projections/coverage against independent original cache reads, actual complete
provider results, identity/corruption rejection and source publication stability.
`EmptyMatrixWarmCheck` verifies that a zero-window DB settles without inference
or an endlessly rescheduled nonempty matrix.

No new Python implementation is present. The existing model and NumPy boundary
are unchanged. This does not implement float32 storage or mmap scoring, remove
the original raw maintenance hints, or establish token/quality/p99 adoption.

See `docs/prepared-vector-matrix.md` and the pinned candidate review for successes,
slower/failed attempts and remaining gates.
