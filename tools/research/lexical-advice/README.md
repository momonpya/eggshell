# Isolated consumed lexical validation

Not adopted. The parent is the frozen `keyed-runtime-20261025/checkout` recorded
by commit `0174ef8` and the previous keyed-native review. Apply integration.patch
to a new copy of that parent and copy the supplied Lean sources into it. Do not
apply the patch to the active product checkout.

LexicalAdvice keeps original source binding in the nomination result, uses the
existing complete lexical index as advice, and defers original indexed/live
ordinal and candidate checks to bounded consumed owners. Ordinary Lean proves
that precomputing query weights preserves the complete reference rank function.

LexicalAdviceAudit retains the prior provider as an independent full-ranking
oracle. Plan questions and three repetitions were fixed before timing. The
fixture also checks the original source trace and invalid consumed owners.

See docs/lexical-advice.md for results/limits and
docs/candidates/lexical-advice-review.json for exact local source, original file,
object, result, receipt, guard and executable-retirement hashes. The Ruby scripts
only build/capture/replay local research artifacts. Runtime extraction, policy
and proofs remain Lean; the existing numerical boundary is unchanged.
