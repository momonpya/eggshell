# Isolated source-scoped native router

Not adopted. Product sources, README benchmark claims and release are unchanged.
This connects the prior window-owner and vector-route components to Warm and
the normal single-DB native discovery producer.

`Eggshell/` contains the new protocol/client/provider and updated router.
`integration.patch` applies to the frozen parent checkout recorded in
`sources.json`; it modifies Handoff, Warm, Main and ContractAudit. Apply it to a
new copy of that parent and copy the supplied sources into that copy. Do not
apply the patch directly to the product checkout or mutate the frozen parent.
The patch passed a dry run against that parent.

The research helpers record a two-DB protocol fixture, atomic router replacement,
and actual first/continued native stdout, publication SHA, ACK and teardown.
`HookScaleRun` optionally reuses an earlier completed preparation after checking
its exact source head and the current product preparation contracts. It still
starts a fresh manager and chat. This is not reuse of an answering-model result.

The Ruby scripts build, invoke and hash local research artifacts. Runtime policy,
extraction, original-record validation and invariants remain Lean. The existing
numerical boundary is unchanged. The local build scripts use the recorded
parent object dependencies; these are local replay instructions, not a portable
product installation.

The final runtime and source/input/object/receipt hashes, guards, failed attempts
and executable retirements are in `docs/candidates/keyed-native-review.json`.
`review-check.rb` checks those local files against the record. Full findings and
limitations are in `docs/keyed-native-routing.md`.

The 50k fixture's final first/continued pair completed semantic search in
11,418/8,162 ms, including manager startup in first. Million-window scale,
required-history recall, all topics/both laps, matched inclusive total-token
improvement, answer quality and p99 remain unqualified.
