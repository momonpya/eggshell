# Isolated admission-policy index

The runtime patch applies with `git apply --unidiff-zero` to the pinned deferred
discovery checkout. It adds the pure index and compiler refinement, imports it
from Matcher and adds ContractAudit entries. Handoff source bytes are unchanged,
but its generated caller must be rebuilt; the review pins the tested C/object.

`PolicyProfile` is a Lean diagnostic derived from the retained discovery helper,
restricted to one broad retrieval-only first request. Its sample is separate from
the unchanged controlled/native comparison cohorts and uses no answering model.

See `docs/admission-policy-index.md` and the review for the source roundtrip,
universal equality proof, final caller-code check, raw outputs and limitations.
This is not a product adoption or a complete persistent authority index.
