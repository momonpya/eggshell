# 選択器の集計を差分更新する

2026-10-29。隔離候補。固定引用診断で27/47を配送した候補`8e01d1d6`の選択結果を一切変えず、利用者の依頼どおり不要な計算を除く。推薦の重み・候補・予算・source scope・認定を変更しない。47は診断一覧であり、全てを質問の必須根拠という分母へ変更しない。

既存のwinner索引は変更箇所だけを更新するが、各更新で`evaluation next`を呼び、選択済み全体のnode/cue集合、費用、価値を再構築していた。既存のmembership索引に新しく追加されたpayload/cueだけを挿入し、その費用と価値だけを加える。

更新結果が`evaluation next`と完全に等しいことをLeanで証明する。membershipだけでなく、canonicalなHashMapの表現と整数の総量まで一致させ、既存の全選択ID・順序の詳細化証明を維持する。原文やDBへ書く処理は追加しない。

検証はまず保存済みの2つのselector inputと旧実行体の全選択IDを使う。大きな整数、重複feature、費用0、重み0、tie、文字数/byteの両上限を含む合成ケースを独立した全走査と比較する。native計時ではIO.Refへの格納で結果を強制し、同じ入力を事前固定の3回測る。改善しない場合は、別の重み・範囲・枠を試さず、この候補を撤回する。

選択が完全一致しても本体採用や98%を主張しない。部品の有効性が確認できた場合だけ実フックの本文一致・期限を確認する。題材1/2/3・両周の総tokenと品質、80人の継続利用は別の未完了条件である。

## 集計の差分化だけでは律速が残った

`Evaluation.advance_exact`は、追加されたnode/cueだけで更新した集計が、全再構成の結果と内部表現まで等しいことを証明する。保存した2入力を各3回再生し、旧実行体の全選択ID・順序・費用が一致した。大きい入力は旧12,461 / 12,329 / 12,239 msに対し11,044 / 11,048 / 11,059 msだった。

さらにcueの値そのものを差分で引く処理も同値性を証明して試したが、11,112 / 11,618 / 11,210 msとなり、追加処理に効果は確認できなかった。この追加moduleとimportは候補から除いた。[棄却したソースと結果](candidates/aggregate-delta/rejected-gain/result.json)を保持し、失敗を採用や改善に数えない。

## CPU標本で逆引きの反復を特定

2秒のnative CPU標本では、workerの1,314標本全てが`State.advance → affected → Incidence.changedStreaming`にあった。winner索引自体は既に存在しており、もう一つ作る問題ではなかった。

共有するファイルのframe nodeが元offerの各行に含まれ、同じfeatureが繰り返される。旧処理は出力offerを重複排除する一方、入力featureを排除していなかった。そのため、同じ巨大なpostingを何度も読み、offerの重複を確認して捨てていた。実入力で選択された728件にはnode参照が21,938個あり、offer内で異なるnode参照は3,815個だった。

候補は、各featureのpostingを最初の一度だけ読む。`DistinctPostings.collect_exact`により、全postingを重複込みで展開してから排除した場合と、出力の全ID・順序が等しいことを任意入力で証明した。hashは桶を選ぶためだけに使い、完全なIDの一致で判定する。順位・tie・重み・候補・上限を変えず、既存の`choose_exact`も再コンパイルした。使用公理は`propext / Classical.choice / Quot.sound`だけで、`sorry`や`native_decide`は加えていない。

## プロジェクトの境界

この変更は選択器の純粋計算だけであり、保存先やcacheの配置を変更しない。利用中プロジェクトの設定が一つのwrite DBを選び、他DBは許可されたread先として扱う。DBの派生物はDB別、読取専用DBの派生物はユーザー側のDB別read-cacheに置く。共通のサービスとRAM上限を、プロジェクトをまたぐshardやcache内容の統合として扱わない。

終了した試験用DB・私有cache・重複実行体の4対象、874,791,047 logical bytesを削除した。現runtimeと依存先に参照が残っていないこと、guardの終了と残存PID 0を確認した。元seed、現runtime/ソース/必要なbuild依存物は保持し、archive・圧縮物は作っていない。[削除記録](candidates/aggregate-delta/retired-data.json)。
