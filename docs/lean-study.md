# Leanによる実験制御と終了済みデータの削除

新seedから題材1・2・3と2周目を実行する前提を [reseed-delivery-contract.json](benchmarks/reseed-delivery-contract.json) に固定した。製品runtimeは `bee29fda3795f53e6cec8a8c7ca198bb408c2a471fe7483d157a61af2d2345d5`、モデルは `gpt-5.6-luna / xhigh`、LLVMは `6dfe1677ab8dffbc6ec13d53a1e0215d75147689`。AGENTSとサブエージェントを無効にし、製品runtimeを変更するなら新seedから再開する。配送を調べる前にDB内の必要記憶を固定し、その未配送を全6段階合計で高々1件に抑える。これは製品への採用条件である同条件・同数複数反復の総トークン、品質、期限の検査に代わるものではない。

## 実験制御

- `StudyBuildMain.lean` は依存関係を読み、既存のLeanライブラリとオブジェクトを使って必要なモジュールだけをビルドする。生成Cはコンパイル後に削除する。旧Rubyのビルド・コピー・ハッシュ・記録用補助は退役した。
- `StudyBootstrap.lean` は隔離したCodex設定のフックを実バイトと照合し、モデルを呼ばないPre/Post/Stop試行と新seedの入力を固定する。
- `StudyMaintenanceMain.lean` は対象を列挙し、終了済みguard、開かれたファイル、シンボリックリンク、保持対象を検査してからDB・キャッシュ・旧補助を削除する。読み取り専用の実験DBでは削除に必要なディレクトリ権限だけを変更する。
- `StudyDeliveryBudgetMain.lean` はダイジェストで結ばれた前段階の判定を累積し、2件目の未配送でモデル投入を拒否する。累積値のLean定理と、6段階で1件の受理・2件目の拒否・runtime違い・履歴変更の拒否を確認した。この判定器自体が必要原文の存在や配送を判定するわけではない。

製品のMiniLM/ONNX/NumPy境界は既存のものを使用する。実験制御、抽出、選択の新しいPython/Ruby実装は加えていない。

## 実際の検査と現在の限界

空DBのモデルなし試行では、4回の実ツール呼び出し、4件の保存元、9件のjournal記録、消費1件・支持4件・共起4件・私有利用4件を確認した。別の私有rootに原本だけを持ち込んだ回復でも来歴は一致した。これらの試行DB・キャッシュ5対象は結果抽出後に削除した。

新しいチャットのseedは、実スレッドで `gpt-5.6-luna / xhigh` と `instructionSources=[]` を確認して実行した。モデルのターンは完了し、115件のフックに失敗はなく、生成の検査も通った。ただし保存daemonが終了期限内に終了せず、取得全体は**失敗**である。guardは残存プロセスを終了し、所有プロセス0件となった。最大集計RSSは2,831,600 KiBで、3.5 GiBの停止値を超えていない。

seed取得で消費した総トークンは **3,472,146**（入力3,452,854、出力19,292、うちcached input 3,252,736）。cached inputとreasoningを重複加算していない。失敗分を除外せずseed費用として記録する。保存・来歴・索引の回復監査が済むまで題材1へ進めない。題材1〜3と2周目の配送合格、削減率、品質、製品採用はまだ主張しない。

## 保持しないもの

終了済み実験のDB・キャッシュ93ディレクトリ、旧Ruby補助67本等、164対象・5,928,093,894バイト（論理サイズ）を削除した。加えて上記のモデルなし試行DB・キャッシュ5対象も削除した。削除先の不存在と現在必要なruntime・モデルの存在を確認し、圧縮やアーカイブは作っていない。実際の空き容量の増加はAPFSの共有extent等の影響を受けるため、この論理サイズと同一とは限らない。

現在の新seedは保存回復と後続試験で使う入力としてのみ保持する。以後も、もう使う予定のないDB・キャッシュは結果抽出後に削除する。実験記録のためにDBを残したり、圧縮して保持したりしない。保存するのはコード、計測結果、受領記録、ダイジェストであり、削除済み入力を使った現在の再検証とは区別する。

実行記録は [lean-study-review.json](candidates/lean-study-review.json)。製品本体・README実績・releaseは変更していない。
