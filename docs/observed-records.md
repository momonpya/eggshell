# Original records survive every output format

Isolated candidate; no production adoption or token-improvement claim.

The previous original-record implementation was still present. Its source hash
matched the fixed study runtime. The supposed regression was not a reverted
patch: a successful partial route had been treated as a complete contract.
Other paths independently required a recognized file-read layout, completed
synaptic traversal, or an exact whole-record quote. The earlier success also
used a different seed and was not an all-six-stage success.

This change removes the first of those conditions from original publication
and reconstruction. It does not claim that the selector's remaining losses,
whole-record quotation matching, or bounded graph traversal are fixed.

## One original domain

The new [ObservedRecords](candidates/observed-records/Eggshell/ObservedRecords.lean)
directory describes the actual saved output: complete bounded raw intervals,
plain-text rows, or checked JSON scalar/member/string-row projections. Tool
names, argument field names, shell commands, external source files and Git are
not inputs to this normalization. A file coordinate is optional additional
evidence. Ambiguous or unavailable file correspondence cannot erase the
original observation.

Only coordinates, representation tags and digests are added. Original plaintext
is not copied into the directory. Metadata is bounded in 64-record blocks and
bound to the database, original owner/Work, body hash and implementation bytes.
The implementation fingerprint includes the source layout and scalar parser;
there is no manually maintained format number. The complete base partition is
checked when loading. Changed blocks fail validation.

The original body, record directory and observed interval use the existing
native source transaction. No second writer or background repair publishes
source metadata. A failed transaction exposes none of them. Retry after lost
ACK leaves the publication unchanged. Source-only reconstruction reads the
same directory without a private journal, prior chat, workspace or model.

Optional JSON projection now falls back to the literal source view on malformed
or noncanonical data. A quote at the beginning of ordinary text is not grounds
for discarding a native observation. Invocation input is canonical JSON when
it actually parses, and literal text otherwise. Background reconstruction no
longer gates originals on the optional output projection.

Ordinary Lean proofs cover every original character in the base partition,
total layout, and preservation of non-derived authority by both directory and
block rows. The new dependency audit checks that publication uses the existing
writer, while replay and catalog lookup cannot publish originals or open a
source file. None of this content correspondence creates Union, Match or
completed authority.
