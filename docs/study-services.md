# Owned services in the memory study

The isolated study now starts the publication service as an owned child before
the first charged turn. It stops the chat daemon first, then the publisher,
checks both actual process exits and endpoint removal, and retains separate
publication cleanup errors. An existing endpoint is rejected without stopping
its owner. Service startup creates no source DB or answering context.

This changes the Lean research harness. The product remains the
`source-authority` candidate with SHA-256
`c7bdbb03c2c03cc03eaab44e144d6d378893d8b6c1e11ea7e108b76d4980c563`.
It is not evidence of better answering-model token use or production adoption.

The admission gate also used an obsolete `actualToolCalls` field. It now
requires the actual producer's positive `nativeToolCalls`, equal portable-origin
count, and `2*n+1` journal events. Missing fields, zero counts, another runtime,
answering-model calls in the native gate, or incomplete cleanup cannot pass.
The publisher's shutdown report is a required frozen artifact.
