# 自然数の重み合計を1走査で求める

隔離候補・未採用。実行物 `34e8faea0af199f990a7b8ad2645f2543f50ebeeab315880e1bbf0c5c85cde44`。親は非空共有payload候補。被覆価値のmap後の再帰的List.sumを、写像と累積を融合したfoldlへコンパイラのcsimpで置き換える。候補・重み・予算・比較順・選択規則は変えていない。

任意の自然数・重み列で合計が等しいこと、benefitとafterBenefitが元の定義に等しいことを通常のLean定理で証明した。浮動小数の丸めは関係しない。参照側は置換対象の関数を呼ばず、親の式を直接記述した。64/512/4,096/16,384 cue、64 offer、重複cue、300bit超の重み、選択済み0〜3件の全限界値を比較し、値と順序が一致した。

16,384 cueの部品比較では、選択済み0件は41→38ms、3件は14→11ms。ただし小さい試行には0msへの丸めもあり、この単発値を全体の性能や総tokenの改善と扱わない。

同じC7 seedの実フック再監査は、最初のwarm中に集計RSS3,694,384KiBで保護停止した。回答モデル0、実フック未実行であり、必要項目を減らしたり、未実行の題材を配送成功として数えていない。停止後の所有processは0。
