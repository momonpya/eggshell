# 製品入口だけを残した比較

隔離した診断であり、採用していない。検索・認定・配送・保存・worker上限は変更しない。
基底`bd9096c4…`の研究用入口から、`Main`だけをimportする[製品入口](ProductMain.lean)へ置き換えた。
入口が`sourceRouteEngine`へそのまま渡すことをLeanで検査した。[公理一覧](laws.txt)。

[291 native object](native.json)は封印した入力と整合し、[290の共通moduleのsource](sources.json)は基底と同一。
通常の製品入口に含めない`Eggshell.ContractAudit`は、研究用入口との比較では欠落として明示されている。
製品の`Main`以下の入口・フック・保存・配送の依存を削ったという意味ではない。
実行体は139,336,192から135,326,688bytesへ減った。

しかし[4組のABBAによる全16起動](startup.json)で、helpの全出力が同じでも高速化は確認できなかった。
parentの8回は243/207/205/205/207/206/207/209ms、candidateは1623/207/203/209/208/204/205/211ms。
平均は211.125対383.75ms。初回の大きい値も除かない。サイズの減少を速度改善として扱わない。
実フック・DB・回答モデルは呼んでいない。性能比較や採用の根拠に拡張しない。

その後、起動スクリプトに旧prefixが固定されていた別の検証不備が見つかった。
このhelp比較は両nativeを直接実行しており、その不備を介していない。
この入口変更の大きな負荷試験は行わず、先に[起動先を揃えた実フック](../../practical-runtime/bound-product/README.md)を検査する。

総token比較0、採用0。終了した隔離実行体/source/prefixは記録を保持して[削除した](retired.json)。
