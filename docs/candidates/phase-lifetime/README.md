Diagnostic only;no product behavior,allocator,clock or worker policy changes.

retention. The same actual compiled parent helper was therefore measured for

does not continue. This does not prove absence of all leaks;it rejects that
short slope as a basis for a service repair.

or tune allocator settings on this evidence. The next investigation observes
actual service owners and transports. All four guards drained successfully;
