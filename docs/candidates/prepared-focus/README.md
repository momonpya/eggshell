# Prepared original-window facts and pure captured reads

Isolated candidate; not adopted. Answering-model calls and paid matched
comparisons remain zero. This work does not establish whole-hook speed,
80-person capacity, real 98% evidence delivery, or token improvement.

The preceding real-request sample found repeated source-window tokenization
inside `focusedEvidenceWindows`. This is distinct from the rejected
whole-owner `subset-rank` change and the rejected per-parent citation cache;
neither is reintroduced. Whole-owner ranking, local per-window IDF, Float
operation order, ties, numerical positions and complete certification stay
unchanged.

Publication compiles the existing original windows once and stores an interned
term dictionary plus ordered window term ordinals in that owner's existing
metadata payload. It checks the complete original window-key directory before
publication. The implementation identity covers the actual tokenizer/ranking
sources. A publication delta updates only changed owners. Decoding uses the
existing bounded shared metadata cache; retained focus facts are included in
the existing query-view byte charge. There is no additional cache allowance.

An intermediate `Loaded.focusWindows` API was rejected: each call reacquired
the mutable metadata cache and updated its borrower/LRU state. That API is
removed. The candidate instead reads the `OwnerMetadataImage.Image` already
captured under the query reservation. Its focus operation has a pure
`Except String (List Nat)` result, takes immutable values, and cannot call IO,
wait for a fill or update a shared cache. The concrete captured-source read
delegates to this operation. No mutex is replaced with CAS or a global mutable
reference. Preparation, admission and release still synchronize their mutable
ownership; this is not a proof that those operations need no ordering.

Kernel laws establish exact dictionary decoding, the same complete rank as
the actual Handoff implementation, original position/budget/uniqueness,
rejection of a foreign pinned identity and changed Work, and preservation of
other owners under immutable insertion. A declaration audit connects actual
publication, decode and captured-read functions and rejects any IO/shared
synchronization or source-window reconstruction in the read dependencies.
The reader API that reacquired the cache must be absent.

The earlier component check passed 480 boundary/multilingual/JSON comparisons
and 1,630 complete ranks over 163 owners/1,205 windows in the 16 protected
synthetic sources. One real journal/publication ACK updated one owner in 11ms;
unchanged owner payloads and the old pinned root remained exact. Those are
component results, not full-hook results. The final captured-read controls
add query reservations, foreign identity/owner/Work/window rejection, and 80
independent readers while both original source-preparation and metadata-cache
mutexes are held. Final results are recorded separately from that earlier
component check. The final controls pass all 1,630 published ranks and 480
pure comparisons, reject the foreign domains, and complete 80 readers in 4ms
while both original mutexes are held. All query reservations are released.
The final one-owner delta takes 12ms. The 13 kernel laws and 1,572 read
dependencies pass; the coherent 254-module native closure changes exactly
the four declared existing source bodies and the new facts module, plus exact
embedded identity bytes. These timings describe components only.

Handoff still needs to consume the prepared ranks through an explicitly
scoped read lifetime. No full-hook or 80-client full-search retry was run for
this candidate. Product source, the active baseline alias and README
performance claims are unchanged. Adoption still requires the requested
matched inclusive-token, quality and deadline comparisons.

The disk guard stopped one build; limits were not raised. Thirty-nine ended
private executable files were removed after recording exact paths and SHA256s.
Required native objects/interfaces/source witnesses, protected originals and
current baseline/candidate executables remain. Completed test DBs/caches/raw
logs are deleted after compact evidence is preserved, without archives.
