# Query-owned typed original views

Isolated candidate,not adopted. Answering-model calls0,paid matched comparisons
0/18. The80-person/eight-hour,growing-project,NAS,98%-real-evidence and
token/quality goals remain open.

The service used to make16 `source-records` self-RPCs and one `source-palettes`
self-RPC per query. It now captures original geometry and selection metadata
in one query-owned view. Geometry bytes are counted before admission and
included in the existing128MiB view budget,with the original32x charge and
active-view bound. Counting holds an existing temporary reply reservation;
waiting requests retain coordinates,not uncharged geometry. After admission,
the captured-byte total is checked against the counted total. Deadline,
capability,scope,complete source head,prepared producer,retained pin and owner
domain checks remain. This fixes previously unaccounted geometry retention;
a query that exceeds the unchanged aggregate budget fails explicitly.

An explicit read/release interface travels from the service to the independent
actor,request environment and source context. It has no publication operation,
wire codec or global callback registry. Local clients borrow immutable typed
values;external clients use one wire adapter over the same checked operation.
The query view owns both values until release. Malformed replies and cancelled
borrowers release their reservations. The old individual-record RPC and unused
record-cache reply field were removed. Vector ranking,synaptic relations,
Work/e-class certification and selection rules are unchanged.

Four kernel laws and the ordinary ContractAudit pass. The declaration audit
connects actor/context/client/service and checks576 captured-read dependencies
for shared synchronization. Native controls compare typed and wire results
against independent original DB geometry,without a network listener. They
exercise two sources plus user-side read-only-profile preparation,foreign
capabilities/scopes/full heads/prepared roots/retained tokens/endpoints,
expiration,malformed-reply cleanup,release during an active borrow and
cancellation. Original heads and final reservations are checked.
