# 旧実装・DB・圧縮保存物の削除

2026-10-25、利用者の指示に従い、旧実装とそのDB・キャッシュ・圧縮した履歴を削除した。アーカイブや退避コピーは作成していない。削除前のパス、サイズ、取得済みのSHAと削除後の検査結果は [storage-cleanup.json](candidates/storage-cleanup.json) に記録した。本文やDBのバックアップではない。

削除したもの：

| 対象 | 件数 |
| --- | ---: |
| 旧実験ディレクトリ | 37 |
| 現在使うモデルの隣に残っていた旧実装等の項目 | 74 |
| 圧縮した旧履歴・アーカイブ | 52（142,501,168 bytes） |
| 旧ベンチマークDBファイル | 49 |
| 不要な生成ファイル・コンパイルキャッシュ | 88 |
| リポジトリとグローバル領域の旧試験キャッシュ | 14 |
| 旧公開版との比較用worktree | 1 |

検証中の候補は `block-score-20261025` の1つに集約した。必要なリンク入力とリソース制御器をそこへ移し、削除した旧実験ディレクトリへのリンク依存はなくした。現在使うMiniLM、5万窓の固定DB、その派生索引と私有キャッシュ、利用者の実際の記憶は保持した。固定DBと字句索引の6ファイルは移動前とSHAが一致している。残る圧縮ファイル15件はLLVMのソーステスト資材と現在のNumPyパッケージのテスト資材である。

削除対象315パスの不存在と、現在のリンク入力134件の存在を検査した。削除後の候補のビルド・ContractAudit・リンクは終了コード0、リソース制限の発火なし、最大合計RSS 1,476,176 KiBで完了した。この検査は配送・品質・トークン改善の認定ではなく、候補も未採用のままである。Phases 0–6は継続する。

以前の文書にある外部実験パスは当時の実行記録であり、今回削除したものを含む。旧DB・旧実行体の再保存はしない。空き容量はAPFSの共有ブロックと他の作業によって変動するため、ディレクトリサイズの合算を解放容量とは扱わない。
